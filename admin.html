الاتصال بـ GitHub

اللوحة دي بتشتغل من المتصفح مباشرة: بترفع الصور وتعدّل ملف البيانات في الريبو بتاعك، وGitHub Pages بيحدّث الموقع لوحده.

بيتخزن في متصفحك إنت بس (على الجهاز ده). ماتشاركوش مع حد.

إزاي أعمل التوكن؟ (دقيقة واحدة)
  1. افتح github.com/settings/personal-access-tokens/new
  2. سمّيه أي اسم، وحدد مدة الصلاحية.
  3. في Repository access اختار Only select repositories واختار ريبو الموقع بس.
  4. في Permissions ← Repository permissions خلّي Contents = Read and write.
  5. اضغط Generate token وانسخ التوكن هنا.
